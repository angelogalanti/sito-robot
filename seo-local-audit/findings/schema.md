# Dati strutturati

30/10/2026. Nel browser locale risultano zero blocchi JSON-LD sulle 18 pagine di contenuto. Mancano anche metadati Open Graph nel layout esaminato.

**Medium, arricchimento:** dopo definizione di URL/identità reali, valutare WebSite per home, CollectionPage per hub e Article/BlogPosting per guide pertinenti. Usare dati coerenti con il testo visibile, senza Product/Offer/Review o rating inventati. Non trasformare `verified` automaticamente in `datePublished`.

L'assenza di markup non dimostra un blocco generale al ranking. La [documentazione Article di Google](https://developers.google.com/search/docs/appearance/structured-data/article) descrive proprietà raccomandate applicabili: non richiede di inventare dati per riempirle.

Nessun JSON-LD implementato, validatore remoto o test di rich result eseguito. Coordinare l'eventuale output SEO/blog per evitare duplicazioni.
